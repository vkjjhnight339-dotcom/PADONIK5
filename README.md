# วิธีรัน
1. ติดตั้ง Node.js 22.5 ขึ้นไป (ไม่ต้อง npm install)
2. เปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน: node server.js
3. เปิด http://localhost:3000 — คนแรกที่สมัครจะเป็นแอดมิน
ข้อมูลทั้งหมดเก็บในไฟล์ shop.db (สำรองไฟล์นี้ไว้)
ขึ้นออนไลน์จริง: ใช้ VPS + Nginx/Caddy ทำ HTTPS แล้วรันด้วย pm2 (pm2 start server.js)
